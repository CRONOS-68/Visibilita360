## 7. Evidenze e limiti

**Legenda certezza**
- **Osservato:** visto direttamente nella pagina pubblica o nelle sue richieste di rete.
- **Dedotto:** conclusione ragionevole da ciò che si osserva (es. "usa un pixel Meta, quindi probabilmente fa campagne social").
- **Non verificabile:** non emerge da informazioni pubbliche.

**Registro delle evidenze**
| Dato | Fonte (pagina/URL) | Data | Metodo | Certezza |
|---|---|---|---|---|
| | | | Analisi REA / lettura manuale | |

**Cosa questo report NON dice**
- Non indica fatturato, traffico reale, budget pubblicitario o clienti del competitor.
- Non accede ad aree riservate, account o dati personali.
- Fotografa il sito alla data indicata: può cambiare.
